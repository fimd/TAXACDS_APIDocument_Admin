Huong dan token (bat buoc)

3 API tren yeu cau staff token trong header Authorization theo dinh dang Bearer <token>.

  • Buoc 1: Goi POST /Staff/loginStaff voi username va password staff.
  • Buoc 2: Lay data.token tu response login.
  • Buoc 3: Truyen vao header Authorization: Bearer <token>.

Xem them vi du curl dang nhap trong trang Common va tung API detail page.
