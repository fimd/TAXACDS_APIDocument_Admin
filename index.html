Hướng dẫn token (bắt buộc)

3 API trên yêu cầu staff token trong header Authorization theo định dạng Bearer <token>.

  • Bước 1: Gọi POST /Staff/loginStaff với username và password staff.
  • Bước 2: Lấy data.token từ response login.
  • Bước 3: Truyền vào header Authorization: Bearer <token>.

Xem thêm ví dụ curl đăng nhập trong trang Common và từng API detail page.

Data test tham chiếu

  • username staff test: string
  • password staff test: string
  • taxNotiNotificationCode mẫu: TAXCDS-NOTI-DEBT-001
  • taxNotiPayerTaxCode mẫu: 0312345678

Lưu ý: cần thay bằng tài khoản và dữ liệu môi trường thật trước khi UAT/production.
