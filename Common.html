Admin Auth Token

API TaxCDSTaxNotification yêu cầu staff token thông qua header Authorization.

1. Đăng nhập lấy token

EndpointPOST /Staff/loginStaff
Body{ "username": "string", "password": "string" }

Ví dụ curl đăng nhập:

curl --location 'http://127.0.0.1:4001/Staff/loginStaff' \
  --header 'Content-Type: application/json' \
  --data '{
    "username": "string",
    "password": "string"
  }'

Response thành công sẽ có trường data.token để sử dụng cho API tiếp theo.

2. Truyền token vào API Admin

Định dạng header bắt buộc:

Authorization: Bearer <staff_token>

Common Error

Các mã lỗi chung trả về trong trường error của response khi API thất bại.

Mã lỗi Mô tả
UNKNOWN_ERROR Lỗi không xác định - hệ thống gặp tình huống ngoài dự kiến.
NOT_FOUND Không tìm thấy tài nguyên yêu cầu.
INSERT_FAILED Thêm mới dữ liệu vào hệ thống thất bại.
API_FAILED Gọi API nội bộ hoặc bên thứ ba thất bại.

Cấu trúc response lỗi điển hình:

{
  "statusCode": 500,
  "error": "NOT_FOUND",
  "message": "Not Found",
  "data": null
}
