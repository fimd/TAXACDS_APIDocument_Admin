Tai lieu tham chieu chung cho bo API Admin TaxCDSTaxNotification: auth token va common error.

Trang chu tai lieu Admin Auth Token Common Error

Admin Auth Token

API TaxCDSTaxNotification yeu cau staff token thong qua header Authorization.

1. Dang nhap lay token

EndpointPOST /Staff/loginStaff
Body{ "username": "string", "password": "string" }

Vi du curl dang nhap:

curl --location 'http://127.0.0.1:4001/Staff/loginStaff' \
  --header 'Content-Type: application/json' \
  --data '{
    "username": "string",
    "password": "string"
  }'

Response thanh cong se co truong data.token de su dung cho API tiep theo.

2. Truyen token vao API Admin

Dinh dang header bat buoc:

Authorization: Bearer <staff_token>

Common Error

Cac ma loi chung tra ve trong truong error cua response khi API that bai.

Ma loi Mo ta
UNKNOWN_ERROR Loi khong xac dinh - he thong gap tinh huong ngoai du kien.
NOT_FOUND Khong tim thay tai nguyen yeu cau.
INSERT_FAILED Them moi du lieu vao he thong that bai.
API_FAILED Goi API noi bo hoac ben thu ba that bai.

Cau truc response loi dien hinh:

{
  "statusCode": 500,
  "error": "NOT_FOUND",
  "message": "Not Found",
  "data": null
}
