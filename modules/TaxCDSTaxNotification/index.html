Admin API Module: TaxCDSTaxNotification

Cac API quan ly va tra cuu thong bao thue cho he thong Admin.

Quay ve trang chu | Mo ban Markdown module

Danh sach API

  • Insert many thong bao thue Insert
    POST /TaxCDSTaxNotification/insertMany
    HTML | MD
  • Tim danh sach thong bao thue Find
    POST /TaxCDSTaxNotification/find
    HTML | MD
  • Tim thong bao thue theo id FindById
    POST /TaxCDSTaxNotification/findById
    HTML | MD
  • Đếm số dữ liệu đối tác nhận được CountByPartner
    POST /TaxCDSTaxNotification/countByPartner
    HTML | MD
  • Đếm tổng số dữ liệu người dùng đã nhận thành công CountNotificationsFeedbackSuccess
    POST /TaxCDSTaxNotification/countNotificationsFeedbackSuccess
    HTML | MD
  • Nhập dữ liệu bằng Excel ImportExcel
    POST /TaxCDSTaxNotification/importExcel
    HTML | MD
  • Đếm tổng số dữ liệu CQT đã gửi CountTotalNotifications
    POST /TaxCDSTaxNotification/countTotalNotifications
    HTML | MD
  • Đếm tổng số dữ liệu đã gửi đến đối tác CountNotificationsSendingToPartner
    POST /TaxCDSTaxNotification/countNotificationsSendingToPartner
    HTML | MD
  • Đếm tổng số dữ liệu đối tác đã nhận thành công CountNotificationsPartnerReceivedSuccess
    POST /TaxCDSTaxNotification/countNotificationsPartnerReceivedSuccess
    HTML | MD
  • Gửi lại thông báo cho đối tác ResendToPartner
    POST /TaxCDSTaxNotification/resendToPartner
    HTML | MD

Headers chung

  • Authorization: Bearer staff token. Vi du: Bearer eyJhbGciOi...

Token flow

  • Dang nhap staff qua POST /Staff/loginStaff voi username/password.
  • Lay data.token tu response.
  • Gan vao header Authorization cho cac API trong module nay.

Xem vi du day du tai Common.html#admin-auth.

Data test tham chieu

  • username: string
  • password: string
  • taxNotiNotificationCode: TAXCDS-NOTI-DEBT-001
  • taxNotiPayerTaxCode: 0312345678
